# factory-plane

A cockpit web app for watching and steering KaaS Factory runs.

**Status: in development.** The repo holds the licence and this note. Nothing here is published or installable yet.

## What it will be

A PWA that shows the runs, gates and costs of a team, and lets an approver act on them. It starts after the factory API lands.
